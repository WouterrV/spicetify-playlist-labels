# Spicetify Playlist Labels

Adds playlist labels to your tracklist indicating the playlists in which a track is included. Clicking a label jumps to the playlist, right clicking removes the track from that playlist.

## Attribution

Originally by Scott Duffey, who was no longer interested in maintaining this project and wrote 'feel free to fork it'.

Using the extension from the old repository, playlist labels weren’t always showing up— likely because Spotify changed parts of the DOM— so this version includes some fixes and should work well. Feel free to send any bug reports.

![Screenshot](screenshot.png)

## Install

Install [Spicetify](https://spicetify.app) and install "Playlist Labels" from the Marketplace, or do a manual install as described in the Spicetify docs.
